# Dataset licence

## Introduction

The fetal ultrasound data used in this project derive from a publicly available segmentation dataset distributed for research and educational purposes. Formal licensing establishes how the data may be used, cited and shared, and defines the obligations of any work that builds upon the original collection.

The subset employed in this study is a **modified educational version** of the source release. It supports the experimental comparison of preprocessing strategies, deep-learning segmentation and morphological post-processing described elsewhere in the project documentation. Compliance with the licence is a prerequisite for reproducible and ethically sound use of the images and annotations.

## Ethical and academic use

Users of this repository should treat the data as **third-party research material**: preserve attribution, do not misrepresent the modified subset as the full Mendeley release, and cite the source publication in any report or publication that uses derived results. The licence does not replace institutional requirements for ethical review of medical image research where applicable.
